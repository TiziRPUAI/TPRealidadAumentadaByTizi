# Unity 6 (6000.4.1f1) & AR Foundation Guidelines

## Context & Environment
- Engine: Unity 6 (6000.4.1f1) for iOS target.
- Package stack: AR Foundation, Apple ARKit XR Plugin, uGUI / UI Toolkit.
- C# standard: C# 9.0+, strictly using modern Unity API.

## Coding Standards
1. Deprecations:
   - Do NOT use `FindObjectOfType<T>()`; use `FindFirstObjectByType<T>()` or `FindAnyObjectByType<T>()`.
   - Use `UnityEngine.XR.ARFoundation` and `UnityEngine.XR.ARSubsystems` namespaces.
2. Architecture:
   - Separate AR scene instantiation logic into Editor scripts (`Assets/Editor/`) using `[MenuItem]`.
   - Keep runtime scripts lightweight and decouple UI from AR logic using events or direct controller references.
3. iOS Compatibility:
   - Avoid desktop-only APIs. Ensure touch inputs are checked via `Input.touchCount` or the new Input System properly.
   - Always verify null references defensively for camera tracking and raycast hits.
